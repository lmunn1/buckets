# Hobby-era concepts (archived)

> Archived because the project pivoted from any hobby to sports beginners (basketball first), and a prerequisite-based skill graph with vision-checked tests replaces these ideas.

## Any-hobby concept

The user typed anything they wanted to learn ("running", "guitar", "sourdough"). The app returned plans for that hobby, and whatever the user chose became a project they tracked over time.

## Blueprints

A blueprint was an AI-generated starter plan for a hobby: overview, milestones, a sample week of sessions, a gear list, and resources. The user could use it as-is, customize it (experience level, days per week, target date, main goal, editable milestones), or build their own from scratch. Blueprints were browsable in a library with featured and saved/modified sections.

## Fire-stage tiers (v0.2)

Each hobby had 5 tiers: Spark, Kindling, Flame, Blaze, Bonfire.

- Each tier held 3 to 5 concrete skills plus a tier test.
- Sessions built practice toward a skill; the user proved it via health data or a self check-in.
- Mastering enough skills unlocked the tier test; passing it leveled the user up.
- A blueprint was a path through the tiers (for example, Couch to 5K went from tier 1 to tier 3).
- There was no separate XP currency.

The v0.2 screens for this (skill tree, skill detail, level up) are in `app/design/wireframe.html`.
