# Kindling

An AI hobby app that gets you started on something new, the way kindling starts a fire.

Type what you want to learn ("running", "guitar", "sourdough") and Kindling generates a **blueprint**: a structured starter plan with goals, milestones, weekly sessions, gear, and resources. Use it as-is, tweak it, or build your own from scratch. Whatever you choose becomes a **project**, a goal dashboard you track over time.

## Screens (v0.1 wireframe)

1. Home: "I want to learn…" prompt, suggested hobbies, continue active project
2. Generating / Results: matching blueprints plus "Start from scratch"
3. Blueprint Preview: overview, milestones, sample week, gear, resources
4. Customize Blueprint: 4 quick questions plus editable milestones
5. Create Your Own: blank project builder
6. Project Dashboard: progress, weekly checklist, next milestone, streak, logs, Ask AI
7. My Projects: all projects with progress and status
8. Blueprints Library: search, categories, featured, saved/modified
9. Profile: stats, active hobbies, settings

Bottom tab bar: Home · Blueprints · My Projects · Profile.
