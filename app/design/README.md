# app/design

The current direction is the near-black/orange basketball UI in [references](references/). The current implementation and validation are documented in the [build report](../FRONTEND_BUILD_REPORT.md); [QA screenshots](qa/) show the implemented frontend, and the [curriculum integration guide](CURRICULUM_INTEGRATION.md) describes the data boundary.

The user's latest handoff and follow-up requirements take precedence over the older product plan: four tabs, one connected graph, and one continuous lesson page with inline practice.

- `wireframe.html`: static wireframe from the general-hobby era (v0.2, pre-pivot). It still uses the old name, blueprints, and fire-stage tiers. Kept as a starting point for layout and components; it does not reflect the basketball skill graph yet. Open it in a browser and scroll sideways.
